# YUVA Intern – Week 2: Data Visualization and Insight Communication using R

## Project Overview
This project completes the YUVA Intern Week 2 task using the Titanic passenger dataset. The objective is to communicate trends, patterns and relationships through multiple R visualizations.

## Dataset
- Titanic passenger dataset
- 891 records
- Public source: https://github.com/datasciencedojo/datasets/blob/master/titanic.csv

## Visualizations
1. Survival Rate by Sex — bar chart
2. Survival Rate by Passenger Class — bar chart
3. Passenger Age Distribution — histogram
4. Age vs Fare by Survival Status — scatter plot
5. Survival Rate Across Age Groups — line chart

## Key Insights
- Observed survival rates differ by sex.
- Observed survival rates differ across passenger classes.
- Passenger ages are concentrated mainly in young-adult and adult ranges.
- Fare values have a wide spread and some high-value observations.
- Age and fare do not form a simple relationship visible from the scatter plot.
- Survival rates vary across age groups.

4. Run `week2_titanic_visualization.R` from top to bottom.
